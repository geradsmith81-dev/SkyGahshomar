Put de440s.bsp (NASA JPL, 32.7 MB) here. On a desktop copy it from C:\AfterglowApp\ephem\de440s.bsp or download it from
https://ssd.jpl.nasa.gov/ftp/eph/planets/bsp/de440s.bsp . If it is missing, sky_engine.load() downloads it once (Streamlit Cloud
does this on its first start). Alternatively set SKY_EPHEM_DIR to a folder that holds it. Range: 1850-2149.
